# 企劃書：《喵淵吞吞樂》

## 一句話企劃與核心樂趣

史萊姆貓化成一灘會走的黏黏坑「喵淵」。拖著它在貓屋雜物間游走，比你小的全吞掉、吞了就變大；吞不下的會把你彈開，等變大再回來一口報仇。一趟最多串 4 間房，每間房的貓門只有吞下「房東貓」才會開。

核心樂趣只留一條：**「剛剛吞不下的，現在一口吞掉」的權力反轉**。連吞、時間經濟、貪吃卡、圖鑑全是為了讓這一口更常發生、更值得炫耀。

這一款比上一款好在哪（對照近期教訓）：
- **變強看得見**：變大是視網膜量得到的面積變化，鏡頭同步拉遠；跨階瞬間 HUD 燈亮＋橫幅＋音效（《喵車衝多遠》「升級感不明顯」的解）。
- **決策密度**：路線投資順序、連吞路徑、追逃跑鬧鐘 vs 守連段、留房清掃 vs 進門、三選一卡——每 10 秒至少一次（聖經 7/29）。
- **後期是新機制不是堆數值**：房間變數（漏淵／濃霧／潮水）與會動的物件，而非加血量（《貓潮突圍夜》《喵舖鼠患》通病）。
- **四個回訪鉤子**：房間解鎖＋星級、30 格圖鑑、功勳徽章、每日一房（《貓潮突圍夜》「無成就系統」）。
- **連吞常駐環**取代閃現橫幅（《喵掌夾殺戰》）；**目標常駐**：開場一句話＋進度條＋房東圖示（《貓窟深潛》）。

## 核心迴圈

| 迴圈 | 週期 | 操作 → 回饋 → 獎勵 |
|---|---|---|
| 微迴圈 | 1.5～3 秒 | 拖曳 → 碰到比自己小的 → 物件縮旋落入 0.3 秒＋音高階梯 → 分數浮字、半徑補間膨脹、連吞環 +1、計時 +0.15～1.2 秒 |
| 中迴圈 | 60～90 秒（一間房） | 小雜物衝體積 → 跨階燈亮 → 解鎖大件 → 吞房東（慢動作＋報仇橫幅）→ 貓門開 → 「清房 vs 進門」→ 三選一貪吃卡 |
| 威脅迴圈 | 持續 | 趟計時器一直流失，只有吞才補；房間變數啟動後逼你動（漏淵半徑倒退、潮水沖走食物、濃霧遮路）；危險物藏在密集區，吞錯就縮、斷連 |

操作＝收割＝升級，中間沒有選單、沒有確認，手一秒都不用停。

## 上癮機制

1. **指數成長的加速度**：半徑線性加、可吞面積平方跳。第 1 個 3 秒吞 1 件，末段 3 秒吞 10 件以上。鏡頭 zoom 隨半徑從 1.0 拉到 0.5，「失控地變強」是全畫面體感。
2. **復仇（delayed payoff）**：每間房的房東貓固定生成在起點 120～260 px、擋在通往貓門的直線上。吞不下時把你彈開並冒嘲諷氣泡（內容包 `taunt`）；吞下時 0.6 秒慢動作＋「報仇！」橫幅＋和弦，而且它就是開門鑰匙。
3. **Near-miss 三處掛點**：(a) 撞到「差一階」物件（尺寸 ≤ 可吞上限 × 1.15）時黃框＋「再吞 N 個」；(b) 時間到結算「差 N 件就能吞下【房東名】」；(c) HUD 常駐「距紀錄 −X」，結算「差 X 分破紀錄」或「新紀錄！」。
4. **歸因於己**：佈局有種子但結構固定（起點 260 px 安全圈只有 T1 食物、房東在旁、危險物永不進圈）。沒有秒死；所有慢性壓力都看得見（潮水有泡沫線＋60 px 預警漸層、漏淵有 ↓ 圖示、霧有明確視距）。輸只有一種：「我路線走爛了」。
5. **損失趨避**：單一趟計時器是流失中的貨幣，吞得越多補得越多，技術直接換遊戲時長。最後 20 秒紅暈＋心跳，最後 10 秒顯示十分位。
6. **變動獎勵**：鬧鐘會逃、後期房東會走、三選一卡從 24 張池加權抽。
7. **完形／掃蕩**：地板空白率＝進度條；清房百分比與 3★（100%）讓「剩三個沒吞」變成癢。
8. **雙目標**：短期＝下一口／保連吞；長期＝總分、串到第 4 房、圖鑑 30/30、功勳。

## 系統與模組

引擎是單檔 HTML，只實作系統；所有房間、物件、卡片、功勳從 `window.SC_CONTENT[key]` 讀。

| 模組 | 職責 | 管理的狀態 | 對外介面 |
|---|---|---|---|
| core | 狀態機（title/run/perk/pause/result/daily）與主迴圈，dt 上限 50ms，timeScale | phase、mode、chain[]、roomIdx、summary | boot()、startRun(order, mode)、enterRoom()、endRun(reason)→SC.over(score) |
| content | 讀四個包、驗證範圍、建索引 | packs、byId、scenesByOrder、warnings | load()、scene(order)、obj(id)、validate() |

| pit | 喵淵位置／半徑／補間／可吞判定／卡片修正值 | x,y,vx,vy,r,targetR,speedMul,captureRatio,gainMul,magnet,hazardMul,slowUntil | move()、canEat(obj)、grow(d)、applyEffects()、tierPips(room) |

| timer | 趟計時：給時、加時、里程碑、低時 | t、refundMul、milestonesHit、low | grant()、refund()、tick()→expired、isLow()、fmt() |
| perks | 卡池過濾、加權抽 3、套用 | taken{id:n}、offer[3] | draw(order)、choose(i) |

**引擎常數（不放內容包）**：起始半徑 r0=16；capture 基礎 0.92；連吞窗口 1.3 秒；里程碑 10/20/30 → +3/+5/+8 秒；一趟最多 4 房；落入動畫 0.3 秒；near-miss 門檻 1.15；低時 20 秒；房東慢動作 0.6 秒 × 0.35；zoom = clamp(1.12 − r/150, 0.5, 1.0)。

**資料流**：content.load → progress.load → ui.title → core.startRun → layout.build(scene, seed=hash(id)+runs) → 每幀 input→pit→objects→rules→timer→camera→render；進門 → perks.draw → ui.perkCards → core.enterRoom；終局 → progress.commit → ui.result → SC.over。

## 內容包規格

### 1. scenes（房間）— 12 筆
用途：一趟的每一站。難度曲線靠 `spawn` 組成、`world` 大小、`layout`、`mod/mod_at`、`time_*` 排出來，引擎不寫死任何一房。

| 欄位 | 型別 | 意義（範圍） |
|---|---|---|
| id / name / order | string / string / int | 唯一 id；有個性的房名；1-12 連續 |
| intro | string | 進房 1.5 秒的一句話（≤18 字） |
| world_w / world_h | int | 800-1600 / 1000-2200 px |
| layout | string | rings（同心環，近小遠大）/ clusters（6-9 群聚，路線題）/ scatter（散佈，距離越遠越大） |
| start / door | array | [x,y] 0-1 正規化；兩者距離 ≥0.5 |
| time_first / time_next | int | 作為本趟首房給 90-150 秒；串接進入給 40-80 秒 |
| spawn | array | [{obj, n}] 生成表，不含 boss |
| boss / boss_dist | string / int | tier 5 物件 id；距起點 120-260 px，放在起點→門的直線上 |
| mod / mod_at / mod_power | string / int / number | none/leak/fog/tide；進房幾秒後啟動；0.5-2 強度 |
| palette | object | {bg, grid, accent} |
| clear_bonus | int | 0-40，進門時 round(clear_bonus × 清房比例) 加秒 |

設計原則：
- 1 房：無危險物、無移動物、T1 ≥ 24 件、mod=leak 且 mod_at ≥ 90（新手第 3 分鐘的壓力源）。
- 每 3 房一個新元素：2 房 wander＋首個危險物；3 房 flee＋鬧鐘；4 房 tide；5-8 房 clusters＋patrol＋房東會走；9-12 房 fog／tide 從 mod_at ≤ 15 起、危險物 ≥ 6。
- **可達性規則**：非 boss 物件 gain 總和 ≥ K × (boss.size/0.92 − 16)，K 從 1 房 2.2 逐步降到 12 房 1.35。K 越低越必須吃到 70% 才能吞房東，near-miss 自然出現。
- 節奏緊→鬆→緊：相鄰房的面積與物件總數交替（密集小房 → 寬鬆大房 → 密集）。
- time_first 150 → 110 緩降、time_next 60 → 50；spawn 總數 55-140；危險物 ≤ 8%；鬧鐘每房 ≤ 3。
- 5 隻房東輪流出現、size 隨房序升、連續兩房不重複。

### 2. objects（吞噬圖鑑）— 30 筆
用途：所有可吞物、危險物、鬧鐘、房東；同時就是圖鑑內容。

| 欄位 | 型別 | 意義（範圍） |
|---|---|---|
| id / name / glyph | string | 唯一 id；繁中名；單一 emoji（純裝飾，尺寸由 size 決定） |
| tier | int | 1-5，5 專給房東 |
| size | int | 半徑 px：T1 9-14、T2 18-24、T3 30-38、T4 46-56、T5 70-88 |
| gain | number | 吞下半徑增量：T1 0.8-1.2、T2 2.0-2.8、T3 3.4-4.2、T4 6.2-7.6、T5 10-14；危險物 −1.5～−4 |
| points / refund | int / number | 分數 T1 2-4…T5 300-600；加時秒 T1 0.15…T5 5 |
| move / speed | string / number | static/wander/flee/patrol；0-140 px/s |
| effect / effect_value | string / number | none / slow（減速秒）/ time（加時秒） |
| hazard / boss | bool | 危險物紅色脈動；房東 |
| color / lore / taunt | string | tier 色系外框；圖鑑一句話 ≤24 字；房東嘲諷 ≤12 字 |

設計原則：tier 分布 T1 6、T2 6、T3 5、T4 4、T5 5、危險物 3（尺寸 T1-2、永遠吞得下）、鬧鐘 1（flee 90 px/s）。色系：T1 綠、T2 藍、T3 紫、T4 橘、T5 金紅、危險物紅。

### 3. perks（貪吃卡）— 24 筆
用途：每次進門三選一，本趟內成長（選擇即獎勵）。

| 欄位 | 型別 | 意義 |
|---|---|---|
| id / name / glyph / desc | string | desc 必寫數值（≤20 字） |
| rarity / weight / min_order | string / int / int | common/rare/epic；1-10；要進入的房序 ≥ 值才出現 |
| effects | array | [{k, v}]，k ∈ speed/capture/gain/combo_window/refund/magnet/hazard_guard/start_size/points/time_now/radar/slow_movers，v 可負（代價） |
| max_stack | int | 1-3 |

設計原則：12 種效果各至少 1 張 common（單一正效果 ≈ +10% 價值）；rare ＝ 大正效果＋一項代價（≈ +20% / −8%）；epic ＝ 雙正效果、min_order ≥ 3、weight ≤ 2。time_now 與 epic 的 max_stack=1。目的是 EV 拉近、不出現必選卡（《肉球快遞隊》《貓窟深潛》教訓）。

### 4. feats（喵功勳）— 20 筆
用途：跨局成就＋淵色／稱號獎勵，明日再來鉤子。

| 欄位 | 型別 | 意義 |
|---|---|---|
| id / name / glyph / desc | string | desc 寫出可量化條件 |
| stat / op / value | string / string / number | 引擎追蹤的 14 個統計鍵；gte/lte；門檻 |
| reward_type / reward_value | string | palette（'hex,hex' 淵色）/ title / none |
| secret | bool | 未解鎖顯示 ??? |

設計原則：每個 stat 至少 1 條、可做 2-3 階；前 3 條第一趟就能解；≥4 條 palette；secret ≤4 且都是自然會發生的行為。

## 進度與存檔

`localStorage["sc_meow_abyss_v1"]`：
- `best_score`、`runs`、`unlocked`（最高可選房序）
- `rooms{order:{best_pct, stars, best_clear_sec}}`：1★ 吞房東、2★ 清 ≥85%、3★ 清 100%
- `dex{objId: count}`：吞過一次就點亮，顯示 lore 與次數；標題頁顯示「圖鑑 21/30」
- `feats[]`、`stats{objects_total, bosses_total, max_combo, best_score, best_rooms_run, runs, full_clears, clocks_total, hazards_total, dex_count, fastest_first_room, clean_rooms_run, stars_total, daily_days}`
- `daily{date, best, streak}`、`tips[]`（首次提示已看）、`palette`（目前淵色）

解鎖規則：任一趟吞下第 k 房房東並走進貓門 → 第 k+1 房成為可選起點。一趟從所選房起最多串 4 房；4 房全清＝勝利終局；第 12 房進門＝「整棟吞光」終局。

|---|---|---|
| 起點 | 1 房，靠彈開學會分階 | 從 5-8 房起跑，知道卡片組合 |
| 目標 | 吞下第一隻房東、活到門開 | 4 房串清、早期房補 3★、圖鑑補洞、破紀錄 |

## 玩法規格

**畫布**：400×600 直式 canvas，dpr 縮放；世界座標 px（房間 800-1600 × 1000-2200）；鏡頭跟隨喵淵，zoom = clamp(1.12 − r/150, 0.5, 1.0)，以每秒 4 倍差值逼近。

**操作**：
- 觸控／滑鼠：畫面任一處按下＝錨點；拖曳向量 ÷ 60 px 夾到 1 為速度比例；向量超過 60 px 時錨點跟著走（無死區）。放開後速度 0.15 秒衰減。
- 鍵盤：WASD／方向鍵（斜向正規化）；1/2/3 選卡；Space／Enter 開始與再來；P／Esc 暫停；M 靜音。
- 速度：190 px/s × speedMul × (1 − 0.15 × min(1, (r−16)/80))；slow 效果與潮水內 ×0.5。

**判定**：
- 可吞：obj.size ≤ r × captureRatio 且中心距 ≤ r。結算在吸入瞬間（即時），0.3 秒縮旋落入動畫是演出。
- 實體：size > r × captureRatio 的物件是障礙。重疊 → 沿法線推出 overlap × 1.6、速度反向 × 0.5、震動 6 px、thud。若 size ≤ r × captureRatio × 1.15 → 黃框＋「再吞 N 個」（N = ceil(差距 ÷ 目前可吞物件平均 gain)）；房東另加嘲諷氣泡。
- 成長：targetR += gain × gainMul（危險物 gain × hazardMul）；r 每秒以差值 × 8 逼近，吞下瞬間 1.06 倍 squash 0.12 秒。漏淵時 targetR 下限 16。
- 磁吸：可吞物件在 r + magnet 內以 90 px/s 被拉。
- 移動物：wander 每 1-2 秒換向；flee 距淵 < 170 + r 時逃離；patrol 沿長軸來回；皆不出界。

**連吞與計分**：
- 間隔 ≤ comboWindow（1.3 秒基礎）→ combo+1；倍率 1 + 0.1 × min(combo, 20)；里程碑 10/20/30 → +3/+5/+8 秒＋橫幅。斷連：超時、彈開、吞危險物。
- 音高階梯：220 Hz × 2^(step/12)，step = min(combo, 24)，tier 加八度層；斷連掉回基音。
- 分數 = points × 連吞倍率 × pointsMul；進門清房分 = round(pct × 200)；勝利時剩餘秒 × 5。
- 加時 = refund × refundMul；進門 = time_next + round(clear_bonus × pct)。
- 終局一律 `SC.over(score)`。

**房間流程**：進房 1.2 秒轉場（房名＋intro）→ 計時開始 → 吞房東 → 門發光＋箭頭 → 可留房清掃 → 淵心進入門圓（半徑 40）→ 計時暫停、三選一 → 下一房；第 4 房進門＝勝利。時間歸零＝立即結算。

**房間變數**：leak：targetR −0.35×power/秒、HUD ↓；fog：可見半徑 260/power + r，看過的物件留 25% 殘影；tide：泡沫線從起點側往門側推進 18×power px/s、60 px 預警漸層，淹沒的物件被沖走（計入未吞）。

**HUD**：頂列（y 0-52）左＝分數（數字補間）＋「距紀錄 −X」/「新紀錄！」、中＝計時 28px（低時紅閃）、右＝房序房名＋⏸；y 56-70 清房進度條＋末端房東圖示（吞下變 ✔）；淵旁＝連吞數字＋窗口耗盡環；左下＝五格「吞得下」燈（本房各 tier 最大物件 glyph，亮＝可吞）；右下＝門方向箭頭／雷達箭頭；y 200 橫幅區。門未開時顯示 🔒 淡影讓人先規劃。

**首次提示（存檔記住）**：首次移動前顯示拖曳手勢動畫；首次彈開顯示「太大了！先吃小的變大再回來」；首次開門顯示「報仇成功！門開了 →」。

## 難度曲線與壓力源

- **第 1 分鐘**：安全圈保證前 5 秒必有 3 次吞食；1 房第 8-12 秒跨 T2（燈亮）；房東彈開教會分階；第 40-70 秒吞房東。
- **第 3 分鐘**：新手仍在 1 房 → 90 秒漏淵啟動（不吃就縮）＋計時 <30 心跳；老手在 2-3 房 → wander／flee 物、首個危險物、逃跑鬧鐘、第一次三選一、K 降到 1.8。
- **第 6 分鐘**：4 房潮水強制節奏（食物被沖走、路線被切）、卡片疊加的膨脹爽、剩餘秒換分的收尾決策。

## 風險與捨棄

- **早期成長慢→無聊**：規則保證 5 個 T1 跨 T2；驗收「15 秒內第一次燈亮」。
- **彈開像雷**：只有明確比你大的是實體；燈與外框色一一對應；near-miss 提示告訴你差幾口。
- **進門／留房其中一邊永遠最優**：清房加秒＋星級＋圖鑑 vs 固定 time_next；只調 clear_bonus。

- **霧太挫折**：只在 9 房後、殘影、視距隨 r 增。
- **emoji 跨平台**：碰撞與尺寸只看 size，glyph 純裝飾，量測失敗退回色塊。
- **效能**：物件 ≤140、粒子 ≤300、離屏剔除。
- **版權**：只借「吞小變大＋復仇」機制與心理學；命名（喵淵、房東貓、貓屋）、視覺（帶貓耳的史萊姆坑）、數值表與程序佈局全原創。

## 驗收清單

1. 開場 15 秒：起點 260 px 內只有 T1 食物、無危險物；任意方向拖 5 秒內至少 3 次吞食回饋；15 秒內第一次「吞得下」燈亮＋橫幅。
2. 房東固定在起點 120-260 px 的門方向直線上；小於門檻碰撞 → 彈開、震動、嘲諷氣泡；吞下 → 0.6 秒慢動作＋「報仇！」橫幅＋門發光＋箭頭。
3. 每次吞食：落入動畫 ≥0.25 秒、半徑可見膨脹、音高隨連吞上升、分數浮字。
4. 連吞數字與窗口環常駐於淵旁；斷連時環消失並降音；10/20/30 里程碑加秒橫幅。
5. 撞到差一階物件顯示黃框＋「再吞 N 個」。
6. 開門後可留房清掃；進門結算顯示清房 %、加秒、星級。
7. 進門出現三張不同的貪吃卡、計時暫停；選卡後下一房開場浮字顯示效果。
8. 第 3 分鐘壓力源：任何一趟累計 180 秒前必出現漏淵／濃霧／潮水之一或移動物件（1 房 leak@90、2 房起 movers）。
9. 計時 <20 秒紅暈＋心跳；歸零立即結算，含「差 N 件吞下【房東】」或「差 X 分破紀錄」或「新紀錄！」慶祝。
10. 「再來一趟」一鍵 <1 秒同起點重開；解鎖、星級、圖鑑、功勳、每日最佳寫入 localStorage，關閉重開仍在。
11. 每日一房同日佈局固定，顯示今日／昨日最佳與連續天數。
12. 勝利（4 房或 12 房）與時間到皆呼叫 SC.over(score)。
